3. Command Reference: How to Run & Verify Everything

1. Check Model Live on Simulated Breath Sound

python "Cnn model\check_model.py"

Loads model, checks 102,019 parameters, simulates a child breath sound, preprocesses into a 128x128 tensor, and prints predicted condition.

2. Print Official Team Evaluation Report

python "Cnn model\print_evaluation_results.py"

Prints precision, recall, F1, and confusion matrix tables for team meetings.

3. Run Pipeline Unit & Integration Tests

python "Cnn model\test_cnn_pipeline.py"

Executes all 6 unit tests confirming zero patient leakage and tensor compliance.

4. Run Inference on Any Child Breath Recording

python "Cnn model\predict.py" --audio "path\to\child_breath.wav" --task disease

5. Connect and Register Model with Gayatri's Django Backend

python "Cnn model\backend_sync.py" --task disease

Registers model in database and removes HTTP 503 errors from backend endpoints.

File NamePurposeImportant Functions & What They Do
config.py Central Configuration DISEASE_CLASSES: 3 disease labels.
PREPROCESSING_CONFIG: 8kHz, Butterworth 50-2000Hz, Mel 128.

build_throat_sound_cnn(): 4-block CNN for adventitious sounds.
verify_model_for_backend(): Validates shapes and layer names.
dataset_loader.py Patient-Grouped Data Loading load_disease_dataset(): Loads .npz, verifies zero patient leakage.
augment_spectrogram(): SpecAugment time/freq masking and noise.
train.py Training Pipeline train_model(): Manages training with Adam, EarlyStopping, ModelCheckpoint.
Automatic export to ml/models/saved_models/.
predict.py Inference Engine predict_breath_audio(): Predicts disease from WAV sound.
print_prediction_report(): Pretty-prints probabilities and bars.

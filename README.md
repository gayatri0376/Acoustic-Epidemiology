# Acoustic Epidemiology

## Project Title
Acoustic Epidemiology: Automated Classification of Pediatric Respiratory Diseases Using Convolutional Neural Networks and Time-Frequency Feature Extraction

## Objective
Develop a research prototype that analyzes pediatric respiratory audio and classifies respiratory sound categories using audio processing and CNN-based machine learning.

## Technology Stack
- Frontend: React
- Backend: Django and Django REST Framework
- Database: MySQL
- Machine Learning: Python and TensorFlow/Keras
- Audio Processing: Librosa, NumPy, SciPy
- Explainability: Grad-CAM
- Version Control: Git and GitHub
